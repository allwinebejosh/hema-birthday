HEMA'S BIRTHDAY WEBSITE

UPLOAD TO GITHUB
1. Open your hema-birthday repository.
2. Click Add file > Upload files.
3. Upload index.html, style.css, script.js, and the images and music folders.
4. Click Commit changes.
5. Wait 1-3 minutes, then open:
   https://YOUR-GITHUB-USERNAME.github.io/hema-birthday/

ADD PHOTOS
- Put your photos in the images folder.
- Name two photos exactly:
  our-photo-1.jpg
  our-photo-2.jpg
- You can add more photo cards by editing index.html later.

ADD MUSIC
- Add an MP3 file to the music folder named:
  birthday-song.mp3
- Make sure you have permission to use the audio.

PERSONALISE
- Edit the birthday letter in index.html.
- The website is public. Only upload photos and details you are comfortable making public.
